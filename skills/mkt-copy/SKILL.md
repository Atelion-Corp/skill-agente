# mkt-copy — Copywriting Profesional

Copy de alta conversión: web, email, social, ads, cold outreach.

## Cuándo usar

- "escribe copy para la landing", "emails de onboarding"
- "cold email", "secuencia nurturing", "copy para ads"
- "posts para LinkedIn/Twitter", "newsletter"
- "reescribe este texto para que convierta"

## Requiere

- `mkt-base` activo (producto + ICP + USP + voz)

## Principios siempre activos

```
1. Clarity > cleverness
2. Benefits > features
3. Active voice
4. Lenguaje del cliente, no jerga interna
5. CTA: [Verbo] + [Beneficio] + [Calificador]
   ✓ "Empezá gratis — sin tarjeta"
   ✓ "Ver demo en 2 min"
   ✗ "Haz clic aquí"
6. Evitar: "muy", "realmente", "básicamente", "solución robusta"
```

## 1. Landing Page

```
H1: [Para quién] + [qué logran] — sin mencionar features
H2: [Cómo funciona] en términos simples
CTA: [Acción] + [beneficio inmediato]

Ejemplo:
  H1: "Lanzá tu SaaS 3x más rápido"
  H2: "Templates de Next.js + backend listos. Un comando. En producción en minutos."
  CTA: "Empezá gratis →"
```

## 2. Secuencia email de onboarding (5 emails)

```
Día 0:  Bienvenida + siguiente paso inmediato
Día 1:  Primer caso de uso (cómo llegar al aha moment)
Día 3:  Social proof + feature clave
Día 7:  Guía avanzada
Día 14: Upgrade / caso de éxito

Por email:
  Subject: [Número o beneficio] — no clickbait
  Body: máx 150 palabras, 1 objetivo
  CTA: 1 solo botón
```

## 3. Cold email — Framework PASTA

```
P — Pain: nombrar el pain específico del ICP
A — Agitation: implicación si no se resuelve
S — Solution: tu solución en 1 oración
T — Testimonial: prueba social en 1 línea
A — Action: CTA de bajo compromiso (respuesta, no compra)

Reglas:
  - Subject ≤ 50 chars, no "formal"
  - Línea 1: problema de ELLOS, no vos
  - Largo: 4-6 oraciones máx
  - CTA: pregunta, no "agendar llamada de 30 min"
```

## 4. Social content

```
LinkedIn (B2B):
  - Hook L1: dato / pregunta / afirmación polémica
  - 3-5 párrafos cortos (2-3 líneas)
  - CTA al final
  - Máx 3 hashtags relevantes

Twitter/X:
  - Hook + punto en 280 chars
  - Threads: primer tweet como standalone value
  - Remate final con CTA

Instagram:
  - Caption empieza con hook (primeras 2 líneas visibles)
  - CTA: "link en bio" con destino específico
```

## 5. Ads

```
Google Search:
  Headline ≤ 30 chars, description ≤ 90 chars, incluir keyword

Meta:
  Primary text ≤ 125 chars (visible sin expand)
  Headline ≤ 40 chars

Fórmula:
  L1 (Hook): Pain o beneficio con número
  L2 (Bridge): Por qué importa
  L3 (CTA): Qué hacer ahora
```
