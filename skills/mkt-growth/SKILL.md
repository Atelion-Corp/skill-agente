# mkt-growth — Growth & Retención

Crecimiento orgánico y retención: churn, referral, comunidad, lead magnets, PLG.

- "reducir churn", "mejorar retención", "por qué se van los usuarios"
- "programa de referidos", "viral loop"

## Requiere

- `mkt-base` activo

## 1. Churn Prevention

```
Señales de riesgo:
  - Sin login en >7 días (early) / >14 días (mature)
  - No completó onboarding
  - Bajó uso >30% vs semana anterior
  - No llegó al aha moment

Intervenciones:
  Riesgo bajo:  email automático con caso de éxito
  Riesgo medio: email + oferta de extensión/descuento
  Riesgo alto:  outreach manual de customer success

Exit survey (al cancelar):
  5 razones seleccionables + campo libre
  Categorías: precio / features / competidor / dejé de necesitarlo / otro
  Acción automática: precio → ofrecer pausa; feature → roadmap update
```

## 2. Referral Program

```
Estructura:
  Incentivo referidor: crédito / descuento / cash / feature premium
  Incentivo referido:  trial extendido / descuento / feature acceso

Mejores prácticas:
  □ Trigger: pedir referido DESPUÉS del aha moment
  □ Link único por usuario sin registro para referido
  □ Double-sided incentive convierte 2-3x mejor que single-sided
  □ Mostrar progreso (cuántos refirió, cuánto ganó)

Copy ejemplo:
  "Invitá un amigo → vos ganás 1 mes gratis, ellos arrancan con 2 semanas extra"
```

## 3. Lead Magnets

```
Alta conversión (B2B SaaS):
  □ Calculadora/herramienta interactiva ("Calculá tu ROI")
  □ Template editable (Notion/Sheets)
  □ Audit gratuito (checklist + resultado)
  □ Benchmark report del sector

Media conversión:
  □ Ebook / guía (solo si genuinamente útil)
  □ Webinar grabado

Criterios del buen lead magnet:
  □ Resuelve un pain específico del ICP
  □ Consumible en ≤15 min
  □ Entrega valor antes de pedir datos
  □ Conecta naturalmente con el producto
```

## 4. Free Tool Strategy

```
Objetivo: tráfico SEO + expertise + convertir

Ejemplos:
  Ahrefs → Backlink Checker gratuito
  HubSpot → Website Grader

Criterios:
  □ Keyword de alto volumen (pain del ICP)
  □ Resultado hace desear el producto completo
  □ Mínima fricción: resultado sin registro
  □ Email solo para enviar resultado por mail

Conversión:
  "Para monitorear esto automáticamente → [CTA producto]"
```

## 5. Product-Led Growth (PLG)

```
Freemium que convierte:
  Free: suficiente valor para adoptar el hábito
  Paid: escala con el uso (no features bloqueados arbitrariamente)

Triggers de upgrade naturales:
  □ "Llegaste al límite de X" → upgrade sin fricción
  □ Feature premium visible pero bloqueado (ver sin tocar)
  □ Sharing/export solo en paid (viral loop)
  □ Invitación de equipo → upgrade para workspace
```

## Output
